3. API Routes

3.1 POST /api/leads

Função:

Busca negócios sem site via Google Places API, com fallback para 50 oportunidades simuladas

Request Body:

{ "profession": "Barbearia", "city": "São Paulo", "state": "São Paulo", "minReviews": 30 }

Response:

{ "leads": [ { "id": "lead-id-1", "name": "Barbearia Nova Era", "rating": 4.8, "reviewCount": 142, "address": "Rua..., São Paulo, SP", "phone": "+55 11 9xxxx-xxxx", "website": null, "mapsUrl": "https://maps.google.com/...", "source": "google" } ], "mode": "google" | "fallback", "notice": "Analisando negócios..." }

Funcionalidades:

  • Integração com Google Places API (5 chaves rotativas)
  • Filtra negócios sem site
  • Ordena por avaliações e rating
  • Fallback automático com 50 negócios simulados
  • Rate limiting por IP
  • Verificação de origem confiável
  • Lida com 12 profissões diferentes

3.2 POST /api/generate

Função:

Gera prompts premium personalizados por profissão via Gemini/OpenAI

Request Body:

{ "business": "Barbearia Nova Era", "segment": "Barbearia", "audience": "clientes locais", "objective": "aumentar agendamentos", "tone": "elegante", "city": "São Paulo", "state": "São Paulo", "leadName": "Barbearia Nova Era", "engine": "gemini" | "openai" | "local" }

Response:

{ "prompt": "Crie um site premium de nível Aether1...", "plan": { "headline": "Barbearia Nova Era: cortes que definem o seu estilo", "palette": { "primary": "#25231f", "accent": "#a9bf46", "background": "#f4f0e7" } }, "mode": "gemini" | "local", "notice": "Brief gerado com Gemini" }

Funcionalidades:

  • Prompts específicos por profissão
  • Suporta Gemini, OpenAI e geração local
  • Personalização por lead selecionado
  • Paleta de cores adaptada ao segmento
  • Inclui estratégia de negócio customizada
  • Copy premium e não-genérica

🎯 Funcionalidades Principais

1. Seleção de Profissão

Grid de 3 colunas com 20 profissões diferentes, cada uma com ícone, etiqueta e descrição de serviços.

  • Hover effect com transformação visual
  • Estado ativo com gradiente preto
  • Ícone em cor lima quando ativo

2. Filtro Geográfico

Seleção em cascata: Estado → Cidade

  • 27 estados brasileiros
  • Cidades carregadas dinamicamente via IBGE API
  • Dropdown com busca

3. Filtro de Avaliações

Seletor numérico para mínimo de reviews desejados

  • Padrão: 30 reviews
  • Range: 15 a 500

4. Busca de Leads

Botão que dispara busca na API /api/leads

  • Loading state com spinner
  • Resultados ordenados por rating e reviews
  • Suporta 50 oportunidades em fallback
  • Mostra mensagem de status

5. Lista de Leads

Cards interativos com informações do negócio

  • Nome e endereço truncados
  • Rating em estrelas
  • Número de avaliações
  • Telefone com botão de cópia
  • Link para Google Maps
  • Badge "sem site"
  • Seleção com borda destacada

6. Geração de Prompts IA

Botões para diferentes provedores de IA

  • Gemini (padrão)
  • Cursor
  • Codex
  • Loading state durante geração
  • Prompt customizado por profissão

7. Painel de Prompt

Exibe o prompt gerado ou padrão

  • Texto expandido com scroll
  • Botão "Copiar para Gemini/Cursor/Codex"
  • Feedback visual após cópia
  • Formatação clara e legível
